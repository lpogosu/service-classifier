# Эксперименты

Здесь лежат не черновики, а проверки, которые определили архитектуру. Каждый
скрипт отвечает на один вопрос и оставляет след в решении: если бы результат был
другим, пайплайн выглядел бы иначе.

Скрипты запускаются как модули из корня репозитория и работают с любым датасетом
в формате кейса — по умолчанию с синтетическим набором из `data/synthetic.py`.
Цифры ниже получены на исходном наборе кейса (2480 объявлений), который не
распространяется; на синтетике они не воспроизводятся и не должны.

| Скрипт | Вопрос | Что установлено | Следствие |
|---|---|---|---|
| `tfidf_detection_baseline.py` | Может ли обучаемая модель заменить словарь на стадии 1? | TF-IDF + OneVsRest: F1 0.800 против 0.929 у ключевых слов. Объединения (union, intersect, fallback) тоже не выиграли | Стадия 1 осталась детерминированной |
| `detection_error_analysis.py` | Откуда берутся FP и FN стадии 1? | Ложные срабатывания концентрируются в нескольких фразах-омонимах на категорию | Покатегорийный `min_matches`, якорные слова, контекстное правило для демонтажа |
| `compare_split_models.py` | Справится ли LLM с решением о разделении? | Семь моделей, лучшая — 0.747 accuracy против 0.848 у GBM | Стадия 2 — GBM, не LLM |
| `compare_split_prompts.py` | Может ли промпт закрыть разрыв? | Пять вариантов инструкции, разброс мал; контрастный вариант — худший (0.584) | Работа над промптом свёрнута |
| `hybrid_gbm_llm.py` | Поможет ли LLM на пограничных случаях GBM? | Исправила 66 решений, испортила 88 | Гибрид отвергнут, в проде чистая GBM |
| `draft_hallucination_audit.py` | Какая модель врёт меньше при генерации? | Qwen3-235B — 36% черновиков с выдуманными фактами, Gemini 2.0 Flash — 1% | Стадия 3 работает на Gemini |

Экспериментам с LLM нужен `OPENROUTER_API_KEY`; остальные работают офлайн.

```bash
python -m training.experiments.tfidf_detection_baseline
python -m training.experiments.detection_error_analysis --top 5
```
